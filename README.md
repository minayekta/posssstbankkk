# دمو بازطراحی پست بانک ایران

این پروژه یک نمونه فرانت‌اند فارسی و راست‌به‌چپ با Next.js 16 و React 19 است. الگوی بصری از طرح Lovable ارائه‌شده آغاز شده و با چیدمان تازه، رنگ سبز و سرمه‌ای، فضای سفید، تایپوگرافی خوانا و نیومورفیسم محدود در کنترل‌ها و کارت‌ها توسعه یافته است.

## اجرا

Node.js 22.13 یا جدیدتر لازم است. پروژه با قالب Sites و لایه سازگار Vinext اجرا می‌شود. پس از خارج کردن فایل ZIP:

```bash
corepack enable
pnpm install
pnpm dev
```

نشانی محلی در خروجی ترمینال چاپ می‌شود (معمولاً `http://localhost:5173`).

برای ساخت خروجی: `pnpm build` و برای بررسی نوع‌ها: `pnpm exec tsc --noEmit`.

## مسیرها

| مسیر | کاربرد |
| --- | --- |
| `/` | صفحه اصلی، دسترسی سریع، خدمات، محصولات، سامانه‌ها، خبر، نمودار نمونه، گالری |
| `/services` و `/services/[slug]` | فهرست فیلترشونده خدمات و صفحه معرفی هر خدمت |
| `/products` و `/products/[slug]` | محصولات و سامانه‌های منتخب و جزئیات |
| `/systems` | راهنمای سامانه‌ها و مسیر آشنایی با هر مورد |
| `/news` و `/news/[slug]` | اخبار، اطلاعیه‌ها، جستجو و صفحه خبر |
| `/tenders` | آرشیو مجزای مزایده و مناقصه |
| `/investors` | امور سهامداران و نمودار کاملاً نمونه |
| `/gallery` | گالری با دسته‌بندی تصویری |
| `/branches` | جستجوی شعب بر اساس ۳۱ استان، شهر و نام؛ نقشه تعاملی و یافتن نزدیک‌ترین نقاط نمونه |
| `/about`, `/contact`, `/search` | صفحات تکمیلی و جستجوی سراسری محتوای دمو |

داده‌های خدمات، محصولات و اخبار در `data/content.json` و داده شعب در `data/branches.json` قرار دارند. فایل شعب شامل ۳۱ استان، ۴۱ شهر منتخب و ۴۵ نقطه نمونه است. انواع و توابع محتوایی در `lib/content.ts` هستند. برای افزودن یک خدمت، محصول یا خبر، مورد جدیدی با `slug` یکتا به آرایه مربوط اضافه کنید؛ صفحه جزئیات از همان داده ساخته می‌شود. اجزای مشترک در `components/` و استایل‌ها در `app/globals.css` قرار دارند. تصاویر نمایشی در `public/images/` هستند. مقصدهای رسمی استخراج‌شده از HTML ارسالی در `lib/official-links.ts` نگهداری می‌شوند.

نقشه شعب با Leaflet و کاشی‌های OpenStreetMap نمایش داده می‌شود. دکمه «نزدیک من» فقط پس از کلیک کاربر مجوز مکان‌یابی مرورگر را می‌خواهد؛ فاصله مستقیم در مرورگر محاسبه و پنج نقطه نمونه نزدیک‌تر نمایش داده می‌شود. لینک نشان، مختصات همان نقطه نمونه را به نسخه وب نشان می‌فرستد. برای نقشه اختصاصی نشان و داده حقیقی شعب، کلید و داده رسمی لازم است. فونت Vazirmatn در خود پروژه بسته‌بندی شده و انیمیشن‌ها برای کاربرانی که کاهش حرکت را انتخاب کرده‌اند غیرفعال می‌شوند.

## وضعیت دمو و گام‌های نسخه واقعی

- متن‌های خبری، آگهی‌ها، نمودار و تصاویر نمونه‌اند؛ هیچ نرخ یا آگهی واقعی اعلام نمی‌شود.
- دکمه‌های ورود همپا، اینترنت بانک، خانه سبز و همتا به نشانی‌های درج‌شده در HTML صفحه اصلی بانک می‌روند؛ صفحات معرفی داخلی هم جداگانه حفظ شده‌اند. فرم بانکی، احراز هویت و تراکنش در این دمو پیاده نشده است.
- اسلایدر و تصاویر شعبه، تصاویر مفهومی تولیدشده برای دمو هستند و عکس مستند شعب واقعی نیستند. گالری به چند پوستر مشخص در HTML ارسالی پیوند مستقیم می‌دهد؛ چون فایل‌های اصلی از این محیط دریافت نشدند، آن‌ها را با کارت پیوند نمایش می‌دهد.
- متن تاریخچه در HTML صفحه اصلی ارسالی نبود. بخش «درباره ما» یک خلاصه کوتاه و مسیر مستقیم به تاریخچه، مأموریت، چشم‌انداز، مسئولیت اجتماعی و حقوق مشتریان در وب‌سایت رسمی دارد. پیش از انتشار رسمی، متن را با منبع بانک تطبیق دهید.
- اطلاعات رسمی شعب، راه‌های تماس، محتوای حقوقی و گزارش‌های سهامداری باید از بانک دریافت و تأیید شوند.
- برای نسخه عملیاتی، API یا CMS با نقش‌های تحریریه، جریان انتشار، تاریخ به‌روزرسانی، پیوندهای رسمی، جستجوی سروری، داده نمودار معتبر، تست دسترس‌پذیری و بررسی امنیتی لازم است.
